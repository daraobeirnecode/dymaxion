# ArcGIS User Types and Licensing Models

Covers the named-user user types that gate what a member can do in ArcGIS Online and Enterprise: Viewer, Contributor (formerly Editor), Mobile Worker (Field Worker), Creator, Professional, and Professional Plus (the GIS Professional tiers that bundle ArcGIS Pro Basic/Standard/Advanced). Explains which capabilities each type carries — Creator can author and publish hosted content, Viewer can only consume shared items, Mobile Worker targets Field Maps/Survey123 data collection. Details the ArcGIS Pro license levels (Basic, Standard, Advanced) and which geoprocessing tools each unlocks, plus extension licensing (Spatial Analyst, Network Analyst, etc.) layered on top. Contrasts named-user licensing (the default: a Pro license assigned to a portal identity, checked out via sign-in) with concurrent-use licensing (a License Manager server pool shared across machines) and single-use licensing. Notes the offline/disconnected checkout workflow for named-user Pro licenses and the 30-day sign-in grace behavior. Includes role vs user type distinction: roles (Viewer, Data Editor, User, Publisher, Administrator, custom) control portal privileges within what the user type allows.
