# CesiumJS 3D Globe

CesiumJS renders a full WGS84 3D globe with time-dynamic support: `new Cesium.Viewer('div', {terrainProvider, ...})` gives camera, timeline, and scene management out of the box. Terrain comes from a `CesiumTerrainProvider` — Cesium World Terrain via Ion (`Cesium.createWorldTerrainAsync()`), or self-hosted quantized-mesh tiles generated by the Cesium terrain builder tools from DEMs. Imagery providers layer over the ellipsoid/terrain: `UrlTemplateImageryProvider` (any XYZ), `WebMapServiceImageryProvider`, `WebMapTileServiceImageryProvider`, `IonImageryProvider` (Bing Maps via Ion), and `ArcGisMapServerImageryProvider`. Two authoring APIs: the Entity API (`viewer.entities.add({position, point/billboard/polygon/model, ...})`) is declarative, handles time-dynamic properties (CZML feeds it directly), and is right for hundreds-to-thousands of tracked objects; the Primitive API (`scene.primitives.add(new Cesium.Primitive({geometryInstances, appearance}))`) is the low-level batched-geometry path for maximum performance and custom appearances. 3D Tiles is Cesium's OGC-standardized streaming format for massive content — photogrammetry meshes, buildings, point clouds — loaded via `Cesium3DTileset.fromUrl(tilesetJsonUrl)` and styled with `Cesium3DTileStyle` expressions; Google Photorealistic 3D Tiles loads the same way via the Map Tiles API. Cesium Ion is the hosted platform (asset pipeline that tiles your uploads, global terrain, imagery, geocoding) requiring `Cesium.Ion.defaultAccessToken` and metered by quota; fully self-hosted alternatives combine your own terrain tiles, imagery endpoints, and 3D Tiles produced by tools like py3dtiles, pg2b3dm (PostGIS buildings to 3D Tiles), or Cesium's own tilers. Choose Cesium over MapLibre/deck.gl when true 3D matters: line-of-sight, subsurface, photogrammetric twins, satellite tracks, or vertical-axis analysis.
